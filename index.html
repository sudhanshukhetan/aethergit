1. Recover a decision

Paste an issue thread, PR diff header or forum discussion. AetherGit extracts what was decided, what was rejected and why, then checks that the quoted evidence really appears in your text.

2. PR firewall

Decisions you anchor above guard their code range. Simulate a pull request and see whether it repeats a rejected idea.

Saved decisions

3. Relink after a rename and edit

Finds the moved function by comparing signatures (50%) with a Ratcliff-Obershelp similarity of the bodies (50%). Relinks at 60% or higher.

4. Contributor graph

One line per identity: source | name | @handle | email, in any field order. Identities sharing an email, handle or name are merged.
