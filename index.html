Roadmap & Planned Features

Upcoming capabilities designed for large repositories and multi-platform teams.

Rename-Resilient AST Relinking

Planned (not built yet)

When files are refactored, moved, or renamed, AetherGit's planned relinker combines AST symbol signature matching with code body SequenceMatcher similarity to preserve architectural decision memory across codebase migrations.

• Tracks functions across file movements and rename operations.
• Prevents historical regression warnings from breaking after renames.

Cross-Platform Contributor Graph

Planned (not built yet)

Unifies contributor identities across Git commits, GitHub PR handles, and issue trackers into canonical profiles to preserve maintainer consensus authority.

• Resolves cross-platform aliases without manual tagging.
• Preserves consensus voting weight across disparate platforms.
